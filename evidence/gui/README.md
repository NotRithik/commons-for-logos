# Native GUI evidence

These images were captured from the actual Commons module running inside Logos
Basecamp on macOS, not generated artwork or a browser recreation.

- `final-allowlist-created.png`: reads the final release's public-testnet
  distribution before its private claims have completed.
- `final-threshold-before-votes.png`: reads the corresponding public-testnet
  group before the proposal/approvals have completed.

These are UI and live-read evidence, not proof that the whole prize flow is done.
The module-only capture excludes other application windows and automatically
collapses configuration paths. Additional older experimental images in this
folder do not establish the final release's deployment or claim counts.
